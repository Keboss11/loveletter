# Aniversario

Proyecto web estático hecho con HTML, CSS y JavaScript Vanilla. El contenido vive en `data/*.json` y el progreso se guarda en `localStorage`.

## Cómo abrirlo

El proyecto está pensado para servirse como sitio estático. Si lo abres desde `file://`, la carga de JSON puede fallar por restricciones del navegador. Usa cualquier servidor estático local, por ejemplo VS Code Live Server.

## Estructura

La base ya incluye navegación, modales reutilizables, halagos, preguntas diarias, caja fuerte y progreso semanal.
